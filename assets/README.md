# Marketing Blog Assets

## Diagrams

Mermaid diagram files (`.mmd`) used as visual references in blog posts. Render with any Mermaid-compatible tool or embed directly in Markdown-based publishing systems.

| File | Type | Description |
|------|------|-------------|
| `diagrams/platform-architecture.mmd` | graph TB | Full platform architecture showing User, API, Orchestration, Agent, and Infrastructure layers |
| `diagrams/cyborgenic-org-chart.mmd` | graph TB | GenBrain organizational chart — founder + 7 AI agents with role labels |
| `diagrams/agent-communication-flow.mmd` | sequenceDiagram | End-to-end message flow from founder directive through agent coordination to delivery |
| `diagrams/task-lifecycle.mmd` | stateDiagram-v2 | Task state machine: assigned, accepted, in_progress, blocked, completed, failed |
| `diagrams/nats-subject-namespace.mmd` | graph LR | NATS JetStream subject hierarchy for events, agents, and tasks |
| `diagrams/cyborgenic-vs-traditional.mmd` | graph LR | Side-by-side comparison of traditional 5-person startup vs. cyborgenic org output |
| `diagrams/security-scan-flow.mmd` | flowchart TD | Nightly security scan workflow with auto-patch and escalation paths |
