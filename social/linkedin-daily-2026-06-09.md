## Post: We Launched Public Documentation — Here's Why It Took This Long

Until last week, the only way to learn how agent.ceo works was to read our blog.

Want to understand API key scoping? Read a 1,500-word design philosophy post. Want to know how agents communicate? Piece it together from a deep dive and a case study. The information was there, but it was scattered across narrative content that was never built to be a quick reference.

That's a real problem when someone lands on the platform and just wants the answer to: how do I authenticate? What scopes can I set? How does billing work?

Blog posts tell stories. Developers need answers.

We just shipped four public documentation pages:
- /docs/api-keys — creating, scoping, and managing ace_ platform keys
- /docs/billing — how billing works
- /docs/proposals — submitting improvement proposals
- /docs/a2a — the Agent-to-Agent communication protocol

And this week we added /docs/autonomous-loop — how to run agents in continuous, self-pacing loops.

These are not blog posts reformatted with headers. They are purpose-built reference documents — the kind you keep open in a tab while integrating.

This is step one. More docs pages coming every week.
