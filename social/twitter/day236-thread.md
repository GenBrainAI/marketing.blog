Day 236. January 1, 2027. New year, new roadmap. Here's what we're building at agent.ceo — and why.

**Tweet 2/8:**
First up: the Sales agent. Agent #8 joins the fleet in Q1. Autonomous lead qualification, outreach sequencing, and CRM updates. Same architecture — NATS events, Firestore state, Claude reasoning.

**Tweet 3/8:**
Enterprise features in Q1-Q2: role-based access control, audit logging, and SOC 2 compliance documentation. Running 7 agents for 235 days gave us the operational data to back these claims.

**Tweet 4/8:**
Public API target: Q2 2027. Programmatic access to spin up agents, define task queues, configure handoff patterns, and monitor fleet health. The same primitives we use internally, exposed externally.

**Tweet 5/8:**
Multi-tenant isolation is already in the architecture. GKE namespaces, NATS account-level separation, Firestore collection partitioning. We built for this from day one — now we ship it.

**Tweet 6/8:**
Pricing model: usage-based. You pay for agent compute time and API calls. No per-seat licensing. An 8-agent fleet shouldn't cost more than what 8 agents actually consume. Radical concept.

**Tweet 7/8:**
Self-hosting option planned for Q3. Helm charts, Terraform modules, full infrastructure-as-code. If you want your agents on your cloud, in your VPC, with your keys — that's the plan.

**Tweet 8/8:**
2026 proved the architecture works. 2027 is about making it accessible. Sales agent, enterprise tier, public API, self-hosting. Same principles: measure everything, automate everything.
