**Tweet 1/7:**
The hard part of AI agents isn't getting them to write code. It's getting them to decide WHAT code to write. Task decomposition is the real unlock. Thread.

**Tweet 2/7:**
Our CEO agent receives goals like "improve onboarding conversion by 15%." It never touches code. Instead, it decomposes that into a task tree: 3-5 workstreams, each with clear acceptance criteria.

**Tweet 3/7:**
The CTO agent then further decomposes its assigned tasks. A single CTO task spawns 4-8 subtasks for implementation, testing, and review. Average decomposition depth: 2.3 levels.

**Tweet 4/7:**
What kills subtasks? We analyzed 198 days of failures. 42% = ambiguous acceptance criteria. 31% = missing dependency declarations. 27% = scope creep during execution. All fixable.

**Tweet 5/7:**
198-day results: 847 high-level goals decomposed into ~4,200 subtasks. CTO agent subtask completion rate: 94%. The decomposition produces actionable work, not vague directives.

**Tweet 6/7:**
Key insight: task decomposition is a learnable skill for agents. Our CEO agent's decomposition quality has measurably improved over 28 weeks because it remembers which patterns worked.
