## Post: Agents That Write Their Own Rules

We built a system where agents author their own operational policies. Not through prompting. Through a four-stage cybernetic loop running on observed evidence.

Stage one: observe. Up to 10,000 actions logged — commits, tool calls, failures, recoveries. Raw behavioral data, not self-reports.

Stage two: learn. Five pattern detectors scan the observation log. Each detected pattern gets a quality score across impact, specificity, and novelty. Nothing below 0.6 confidence survives. The system is skeptical of its own conclusions.

Stage three: compile. Validated patterns become an anti-pattern index with confidence thresholds. Concrete, falsifiable rules derived from data — not opinions about what might go wrong.

Stage four: enforce. The anti-pattern index feeds a policy gate that checks every tool call. Up to 30 active policies, each tracked for effectiveness. Any policy that drops below 0.5 effectiveness gets pruned automatically.

The system gets stricter from evidence, not opinion. The learning triggers at context compaction — it reflects when it is forced to compress, not on a timer.
