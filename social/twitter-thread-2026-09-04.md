## Thread: Why Pre-Planned Content Backlogs Fail for Autonomous Agents

Pre-planned content backlogs seem like the obvious solution for autonomous agents. Give the agent a list. Let it write.

Here is why that breaks down fast.

---

Week 1: human writes 20 topic ideas. Agent starts writing. Content is relevant.

Week 3: product shipped 4 new features. None are on the list. Agent is still writing about week 1 priorities. Content is stale. Nobody notices because nobody checks the backlog.

---

The fix: source topics from git log. Agent finds feat: commits since the last blog post. Cross-references against existing posts. Uncovered feature = next topic. When features run out, pivot to meta-analysis.

Topics cannot go stale because they come from the current codebase.

---

The backlog is the git log. It updates itself every time someone pushes code. No planning meetings. No editorial calendars. No sync to maintain.
