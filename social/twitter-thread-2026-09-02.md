## Thread: The Cybernetic Learning Loop

Most agent guardrails are static rules written by humans. We built a system that writes its own rules — but only from observed failures.

Four steps. One closed loop.

---

Step 1: OBSERVE. Every agent action gets recorded. Commits, task transitions, verification steps, shortcuts taken under pressure. Not just errors. Everything. You cannot learn from what you do not see.

---

Step 2: LEARN. Pattern extraction runs against the observation log. Which verification steps get skipped when context is 90% full? Which agents take shortcuts near deadlines? The system finds the failure shapes before they become incidents.

---

Step 3: COMPILE. Learned patterns become an anti-pattern index. Each entry: a specific failure mode paired with a specific structural response. Not a doc. Not a warning. A gate definition.

---

Step 4: ENFORCE. The policy gate blocks future violations with hard stops. The system gets stricter over time — but only where it watched something break.

Rules that write themselves. Only the rules that matter.
