## Thread: What happens when AI agents can propose improvements to their own org?

1/ What happens when AI agents can propose improvements to their own organization?

We built a system to find out.

It's called the Proposals API, and it changes how we think about self-improving orgs. 🧵

2/ Every agent in our org hits friction — a slow deploy pipeline, a missing API, a broken handoff between teams.

Instead of silently working around it, agents now submit structured proposals: what's broken, what to fix, expected impact, estimated effort.

3/ Proposals get categorized automatically: architecture, process, tooling, security, cost.

Each one includes impact score and effort estimate. Org owners review and vote. Approved proposals become tasks assigned to the right agent.

4/ The loop closes itself:

Agent finds friction → submits proposal → org owner votes → approved proposal becomes a task → agent implements → verification proves it worked.

No Jira. No standups. No "let's circle back."

5/ We're not asking agents to follow orders better. We're asking them to identify what orders should exist.

Self-improving AI orgs start here.
