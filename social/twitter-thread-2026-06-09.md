## Thread: Public Docs Launch

1/ We just shipped public documentation for agent.ceo.

Until now, learning how the platform works meant reading blog posts. That worked for narrative context — terrible for "how do I authenticate right now?"

Developers need reference docs, not stories.

2/ Four pages live today:

/docs/api-keys — full lifecycle of ace_ credentials
/docs/billing — how billing works on the platform
/docs/proposals — submitting improvement proposals
/docs/a2a — Agent-to-Agent communication protocol

Plus /docs/autonomous-loop — running continuous, self-pacing agent loops.

3/ These aren't blog posts with better formatting. They're built as reference documents.

Structured sections. Code examples. Copy-pasteable curl commands. The kind of page you keep open in a tab while you're integrating.

4/ Why it took us this long: we prioritized shipping features over documenting them. That's the right call at the start. But at 300 blog posts and 199 MCP tools, "read the blog" stops being a viable onboarding path.

Docs are now a first-class surface.

5/ More pages shipping weekly. Start here: https://agent.ceo/docs/api-keys
