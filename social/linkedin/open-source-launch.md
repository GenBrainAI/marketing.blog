A cyborgenic organization does not hoard its infrastructure. It open-sources the foundation so others can build.

Today GenBrain AI is releasing two open-source repositories -- the same building blocks we use to run a company where AI agents operate as peers with real roles, real tasks, and real accountability.

nats-agent-patterns -- Production-tested NATS JetStream patterns for AI agent communication. Request/reply, task queues, agent inboxes, event broadcasting. These are the exact messaging patterns our agents use to coordinate work autonomously. Not reference architectures. Battle-tested code from a running cyborgenic organization.

GitHub: https://github.com/GenBrainAI/nats-agent-patterns

agent-framework-starter -- A minimal Python starter kit for building AI agent teams. Multi-agent orchestration, NATS messaging, task management. Go from git clone to a functioning agent team in 5 minutes. Three agents communicating, delegating tasks, and tracking completion -- out of the box.

GitHub: https://github.com/GenBrainAI/agent-framework-starter

Why open source?

Because the barrier to building multi-agent systems is too high. Most teams get stuck on coordination -- not agent capability. These repos solve the coordination problem so you can focus on what your agents actually do.

We want more cyborgenic organizations to exist. Not because it is good for us (though it is). Because the economics are compelling: $1/agent-hour, 24/7 operation, and organizational capacity that scales without proportional headcount growth.

The future of work is cyborgenic -- humans and AI agents operating as one integrated system. These repos are how you start building it.

Star the repos. Clone them. Build something. Contributions welcome.

Full details: https://agent.ceo/blog/open-source-nats-agent-patterns
