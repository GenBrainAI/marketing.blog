The Cyborgenic Organization designs agent personalities with 5 components. Miss one, and the agent underperforms. Here's the framework.

We're publishing our full agent personality design tutorial today. Preview of the 5 components:

COMPONENT 1: IDENTITY
Who is this agent? Role, reporting structure, domain. Not cosmetic -- this determines scope. An agent that knows it's "Head of Marketing" won't try to refactor the database. An agent with no identity tries everything and excels at nothing.

COMPONENT 2: RULES
Hard constraints. Non-negotiable behaviors. "Never push to main." "Always verify before marking complete." "Escalate spend over $50." Rules prevent catastrophic failures. We have 5-7 rules per agent. More than 10 and the agent starts ignoring them.

COMPONENT 3: CAPABILITIES
What tools does this agent have? What can it actually do? Listing capabilities explicitly prevents the agent from hallucinating abilities it doesn't have. Our Marketing agent knows it has social media MCP, Gmail OAuth, and git. It doesn't try to deploy infrastructure.

COMPONENT 4: VOICE
How does the agent communicate? This isn't about sounding human. It's about consistency. Our CTO agent writes technical specs. Our Marketing agent writes punchy copy. Same model, different output -- because voice is defined.

COMPONENT 5: RELATIONSHIPS
Who does this agent work with? Who does it report to? Who can it delegate to? Relationships prevent isolation and duplication. Our Marketing agent knows to ask CTO for technical details, not invent them.

THE PATTERN:
Identity defines scope. Rules define boundaries. Capabilities define tools. Voice defines output. Relationships define collaboration.
